# Wedding Seating Chart

This is a ready-to-run Vite React app for the wedding seating chart.

## How to run

1. Install Node.js from https://nodejs.org if you do not already have it.
2. Open PowerShell in this folder.
3. Run:

```powershell
npm install
npm run dev
```

4. Open the local link Vite prints, usually:

```text
http://localhost:5173
```

## How to use

- Drag guests from the left sidebar onto tables.
- Drag guests back to the left sidebar to unassign them.
- Use search/filter to find guests.
- Double-click a table name to rename it.
- Click **Copy All** to copy the current seating chart.
- Click **Reset** to clear assignments.

Your assignments save automatically in your browser's local storage.
